Course Project Requirements
Project Task

Create automated test scenarios for an e-commerce website of your choice (it must be an online store so that all criteria can be fulfilled), or use the following demo website:

https://www.saucedemo.com/

The automated tests should cover the following scenarios:

1. Successful Login

Create a test that verifies a user can successfully log into the system using valid credentials.

2. Unsuccessful Login

Create a test that verifies the system displays the appropriate behavior when invalid credentials are used.

3. Add Products to the Cart

Create a test that adds products to the shopping cart.

Requirements:

Add at least two products.
The products should be provided as parameters (data-driven approach).
4. Checkout Process

Create a test that completes the checkout process for products already added to the cart.

Note:
This test must be different from the "Add Products to the Cart" test described above.

5. Additional Scenario (Bonus)

Investigate the issues and limitations of the problematic users available after logging into the application.

Create one additional automated test based on your findings.

Example:
A test that validates a specific issue or broken functionality related to one of these users.
